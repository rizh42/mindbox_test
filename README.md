# Тестовое задание Mindbox

## Задание 1
Напишите на C# или Python библиотеку для поставки внешним клиентам, которая умеет вычислять площадь круга по радиусу и треугольника по трем сторонам. Дополнительно к работоспособности оценим:

- Юнит-тесты - done
- Легкость добавления других фигур - done
- Вычисление площади фигуры без знания типа фигуры в compile-time - done отчасти, т.к. код реализован на Python, в котором нет вычислений в compile-time
- Проверку на то, является ли треугольник прямоугольным - done

### Файлы:
1. shapes.py - файл с реализацией логики хранения фигур
2. tests.py - файл с юнит-тестами

## Задание 2
В PySpark приложении датафреймами(pyspark.sql.DataFrame) заданы продукты, категории и их связи. Каждому продукту может соответствовать несколько категорий или ни одной. А каждой категории может соответствовать несколько продуктов или ни одного. Напишите метод на PySpark, который в одном датафрейме вернет все пары «Имя продукта – Имя категории» и имена всех продуктов, у которых нет категорий.

### Файлы:
1. get_products.py - файл с реализацией логики задания
